# Decimal to Binary Converter

This project contains a Python script that converts a decimal string into its binary equivalent. The script also includes input validation to ensure that the input is a valid number.

## Features

- Converts a decimal number to a binary sequence.
- Validates the input to ensure it contains only numerical digits.
- Provides user-friendly prompts for input correction.
- Jenkinsfile to test new commits

## Getting Started

### Prerequisites

- Python 3.x installed on your system.

### Running the Script

1. Clone the repository or download the script file.
2. Open a terminal or command prompt.
3. Navigate to the directory containing the script.
4. Run the script using the command:

   ```bash
   python3 decimal_to_binary.py

5. Follow the on-screen prompts to enter a number.

### Running the Tests

1. Ensure you have unittest (comes pre-installed with Python).
2. Navigate to the directory containing the test file.
3. Run the tests using the command:

    ```bash
    python3 test_decimal_to_binary.py

### Example

    Enter the number you want to convert to binary: 34
    Number is: 34
    Binary sequence is: 100010

## Jenkins Pipeline Configuration and Setup

### Steps

1. Create Jenkinsfile in the base directory of the project.
2. Install jenkins on your device

    ```bash
    brew install openjdk@11
    brew install jenkins-lts

3. Start your jenkins instance

    ```bash
    brew services start jenkins-lts

4. Complete the jenkins set up, installing the recommended plugins (RECOMMENDED: Create an admin user)
5. Create and configure your new pipeline
6. Install ngrok to be able to provide a public IP for GitHub to access for the webhook

    ```bash
    brew install ngrok  

7. Create your ngrok account and add your authentication token.
8. Use the appropriate command to generate a public url for your jenkins instance (this example uses a local instance)

    ```bash
    ngrok http http://localhost:8080

8. Navigate to your project on GitHub and configure a new webhook using the url generated by ngrok
9. Now if you push a new commit in the 'main' branch, the pipeline should be triggered
